# Source dataset — Spain wage determinants project

The project bundle includes the source CSV provided by the author:

- **Path:** `data/raw/salarios_INE_2022_sample.csv`
- **Stated source:** Spanish National Statistics Institute (INE), 2022 wage survey (sample used for UOC Activity 3)
- **Rows:** 10,000
- **Original columns:** 56
- **Encoding:** UTF-8-compatible CSV, comma-delimited
- **SHA-256:** `6659bd0358adbeb671ac46ea27026c1dbe9781ea17294fe7838f48f9cc1bb9ce`

The R Markdown document reads this file via a relative path, so it can be executed from the project root without modifying absolute paths.

## Use and redistribution

The file is included in the **locally downloadable project ZIP** to reproduce the academic exercise. It is **excluded from Git tracking** by `.gitignore` while the right to publicly redistribute the underlying microdata is unverified. Do not commit it to a public GitHub repository or redistribute it separately until you have confirmed the relevant INE dataset license, conditions, and privacy safeguards.

The original report also references the variable dictionary `dr_EES_2022.xlsx`, which is not included and is not required for executing the analysis code.
